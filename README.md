# NeonReader / Chitalka

Браузерное приложение для чтения электронных книг с пользовательскими настройками и функциями синтеза речи.

## Задача
Создать лёгкую читалку с удобным чтением, навигацией по содержимому и доступными функциями TTS без сложной серверной инфраструктуры.

## Что показывает проект
- Разработка полноценного клиентского веб-интерфейса.
- Работа с текстовым контентом, навигацией по главам и локальными пользовательскими настройками.
- Интеграция с возможностями синтеза речи браузера (доступность зависит от браузера и системы).

## Запуск
Откройте [index.html](index.html). При включённой публикации GitHub Pages приложение можно развернуть как статический сайт. Возможности и форматы следует проверять в используемом браузере.

## Технологический подход
HTML / CSS / JavaScript, клиентское хранение данных, браузерные API. Проект создан с AI-assisted разработкой и последующей проверкой сценариев автором.
