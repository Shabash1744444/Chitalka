# NeonReader

Браузерная читалка с озвучиванием. **Проект в разработке.**

## Как проверить
1. Откройте [веб-версию](https://shabash1744444.github.io/Chitalka/).
2. Нажмите **«Открыть пример»** — приложение загрузит короткий оригинальный текст без обращения к сторонним книжным сайтам.
3. Проверьте настройку размера и стиля шрифта, переход между фрагментами, закладку и управление воспроизведением. Для теста озвучивания используйте **«Системный голос (Оффлайн)»** — наличие русского голоса зависит от браузера и ОС.
4. Для собственного документа выберите **«Открыть TXT / FB2»**. Локальный импорт поддерживает текстовые файлы до 5 МБ (UTF-8 и Windows-1251). Загрузка книги в локальном режиме не зависит от книжных сайтов.

## Реализованная функциональность
- Отображение текста, регулировка оформления и размера шрифта.
- Системное озвучивание и экспериментальный онлайн-режим TTS.
- Сохранение закладок и позиции чтения для загруженных по URL глав.
- Локальный импорт TXT/FB2; пробный текст для публичной демонстрации.
- Библиотека URL-источников, кэширование глав в IndexedDB и экспорт собранных глав в TXT/FB2.

## Известные ограничения
- Не все сайты разрешают загрузку глав через браузер: внешние прокси могут быть недоступны или блокироваться. Онлайн-TTS также зависит от стороннего сервиса.
- Импортированный локальный файл читается в текущем сеансе и не сохраняется как полноценная офлайн-книга в библиотеке.
- EPUB и PDF как форматы книг для импорта не поддерживаются.
- Полная регрессионная проверка на разных браузерах и устройствах пока не проведена.

Этот репозиторий содержит демонстрационную веб-версию. Интерфейс и функции продолжают дорабатываться.
